# chordlite · 和弦听辨训练器

> 拖进一首歌，看见它的和弦，再听清那里面是什么色彩。
>
> 一个**教和弦色彩**的本地工具，不是排行榜识别器。

---

## 下载

到本仓库的 **Releases（发行版）** 页面，下载最新的 `chordlite_*.zip`。

**解压后双击 `chordlite.exe`**，访问码 **0721**。

> `chordlite.exe` 必须和 `venv\`、`app\`、`models\` 放在同一个文件夹里。
> 它是启动器不是独立程序，请**整个文件夹解压**，不要把 exe 单独拖出来。

**不用装 Python。** 第一次分析要加载模型，等 20-90 秒；同一首歌第二次是秒回。

> 国内建议用 Gitee 下载（GitHub 可能很慢或打不开）。

## 它能做什么

| 板块 | 适合的曲子 | 实测准确率 |
|---|---|---|
| **流行 / 摇滚** | 三和弦为主的流行歌 | 三和弦 **0.863**（38 首人工标注的真实歌曲） |
| **日系 J-Pop** | 王道进行、丸之内进行那类 | **0.9036** / J-Rock 0.9167 |
| **爵士** | ii-V-I、Rhythm Changes | 中位 **0.674**，色彩族 0.795 |
| **钢琴独奏** | 只有钢琴、没有伴奏 | 块状和弦 **99.2%** |
| ~~复杂类摇滚~~ | 多层编曲、频繁转调 | **没做**，见下 |

---

## 三个必须先说清楚的事

### 1. 四个板块不是四个模型

只有**两个引擎**：ChordNet（前三个板块共用）和 ByteDance 钢琴转谱（独奏）。

前三个板块的差别在**后处理**，不在模型：

- **日系** = 解码 + 色彩提示层（只加注释，**和弦名一个都不改**）
- **爵士** = 解码 + 标注层（只把 sus4 改成 maj，其余不动，并保留原判）

所以同一首歌在「流行」和「日系」里，**和弦名字是完全一样的**。这不是 bug。

### 2. 准确率是有条件的

- 流行 0.863 不含复杂编曲。38 首里结构最复杂的 Bohemian Rhapsody 只有 **0.619**。
- 爵士的 sus4 精度实测 **0.00**（全错），所以界面上把它中和掉并标注「已中和」。
- 钢琴独奏只支持钢琴。**单音输出「空」是正确的**，不是出错。

### 3. 复杂类摇滚没做

界面上有个灰色标签，点开有完整说明。简短版：手里没有标注素材，做出来也无法验证，所以不做承诺。

## 关于示范音频

界面上的「用示范音频试一下」放的是**程序合成的和弦进行**，不是任何唱片。

这样做有两个原因：一是不能把有版权的录音打包进公开下载；二是这样演示的正好是这个板块
要教的那条进行（点哪个板块，就听哪个板块的核心进行）。

## 界面

- 四个板块**布局结构各不相同**，不是换配色
- 每个板块记住自己的分析结果，切走再切回不用重跑
- 和弦名用乐谱写法：`C` `Am7` `C/E`（不是 `C:maj` `C:maj/3`）
- **自动识别调性**，并据此决定升号还是降号（Bb 大调里就写 `Bb`，不写 `A#`）。
  调性把握不大时不会硬改，界面会标出「不确定，保持原拼写」
- 每个和弦右侧有结构图，**一根竖条 = 一个和弦音**
- 时间轴每个和弦都保证名字可读，放不下就横向滚动

## 速度（纯 CPU）

| 板块 | 3 分钟的歌 |
|---|---|
| 流行 / 日系 | 20–40 秒 |
| 爵士 | 60–100 秒 |
| 钢琴独奏 | 100–140 秒 |

第一次运行还要加载模型（多 20–60 秒），之后同一首歌秒回（有缓存）。

## 已知限制

| 限制 | 说明 |
|---|---|
| 只支持 Windows | 路径和启动器都是 Windows 的 |
| 只支持钢琴独奏 | 转谱模型是钢琴专用 |
| 琶音不报和弦 | 只给色彩提示，这是刻意的 |
| 复杂摇滚没做 | 见上 |
| 单机单用户 | 本地服务，没有并发设计 |
| 访问码可绕过 | `0721` 写在前端，看源码能找到。拦的是手滑，不是攻击 |

## 技术构成

| 部分 | 用了什么 |
|---|---|
| 和弦识别 | [ChordNet](https://github.com/music-x-lab/ISMIR2019-Chord-Recognition)（MIT）+ ChordMini ONNX |
| 钢琴转谱 | [piano_transcription_inference](https://github.com/bytedance/piano_transcription)（MIT） |
| 音频分析 | librosa（ISC）、PyAV（BSD）、soundfile（BSD） |
| 深度学习 | PyTorch 2.5.1 **CPU 版**（BSD-3） |
| 界面 | 纯 HTML/CSS/JS，**没有构建步骤** |

第三方声明见 [NOTICE.md](NOTICE.md)。
